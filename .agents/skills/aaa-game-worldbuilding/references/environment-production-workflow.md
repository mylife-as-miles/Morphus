# Environment Production Workflow

## 1. Establish the game

Infer the player fantasy, camera, traversal, world size, critical route,
interaction or combat needs, landmark, hardware target, and quality preset.
Choose strong defaults for an underspecified ambitious request.

## 2. Compose before detail

Set a player route, foreground frame, midground subject, background landmark,
height hierarchy, biome regions, water flow, spawn, and showcase view. A world
is designed around decisions, not merely scattered.

## 3. Natural foundation

Use procedural systems for geological massing, erosion, rivers, lakes,
moisture, snow, biomes, vegetation, water, atmosphere, weather, lighting, and
post-processing. Use authored tools for villages, roads, bridges, ruins,
dungeons, props, gameplay objects, and hand-made landmarks.

## 4. Gameplay spaces

Create a valid player spawn, continuous walkable ground, readable entrances,
human scale, deliberate elevation change, orientation landmarks, points of
interest, and routes through or around cliffs and water. Do not let procedural
terrain create inaccessible objectives.

## 5. Dress and grade

Use ecological distribution and surface-specific dressing. Vary age, scale,
condition, and orientation. Add ground detail nearby and structure at distance.
Then set time, subject light, exposure, cloud placement, fog, and color so the
route reads without hiding work.

## 6. Iterate

Capture, compare, identify the top three visual deltas, fix them, and capture
again. Continue through refinement rather than stopping after first generation.
